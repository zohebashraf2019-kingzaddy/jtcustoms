# JT Custom Autos — jtcustomautos

Website for **JT Custom Autos** (Reno, NV) — starlight headliners, suede wraps, ambient lighting and mobile headlight restoration.

## Highlights
- **Starlight Studio** (`studio.js`): live canvas preview of a starlight headliner from inside the cabin
  - Body styles: sedan, coupe, SUV, truck, van — plus a **custom demo** for any year/make/model (auto-detects cabin shape)
  - 300–1000 stars (kit presets 300 / 450 / 600 / 830 / 1000), fiber mix, brightness
  - Single, two-tone, multicolor and color-flow modes with 11 colors + custom picker
  - Twinkle speed, shooting stars, ambient lighting, sunroof with star outline, headliner material, custom name/logo in stars
  - "Request this build" copies the build and opens the Instagram DM; "Copy share link" saves the build in the URL
- Services, packages (preview any kit in the studio), process, video reels, headlight before/after slider, booking + FAQ

## Stack
Static HTML/CSS/JS — no build step. Deploy on Vercel as a static site (Framework preset: **Other**, root `/`).
